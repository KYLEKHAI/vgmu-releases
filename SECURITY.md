# Security & Vulnerability Reporting

## Reporting Security Vulnerabilities

**Do not open a public GitHub issue to report security vulnerabilities.** Public disclosure puts users at risk and may prevent timely fixes.

### Private Reporting

Use GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](../../security) of this repository
2. Click **"Report a vulnerability"**
3. Describe the vulnerability, steps to reproduce, and potential impact
4. Submit — your report will be reviewed within 7 days

Alternatively, email security concerns directly to: **kylekhai04@gmail.com**

Include:

- Vulnerability description
- Steps to reproduce
- Potential impact
- Your contact information (optional)

### Responsible Disclosure

Please allow reasonable time for a fix before any public disclosure.

## Known Limitations

- vgmu depends on a third-party online catalog, which may have its own security and availability issues
- The app does not operate a server or account service, so most security concerns are on-device
